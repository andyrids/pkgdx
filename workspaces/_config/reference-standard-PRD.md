- Sole focus is to elicit the situation and motivations of your customers' jobs-to-be-done
- One job story can be solved by multiple user stories
- A goal can be achieved with a number of different solutions, but the effectiveness of each solution
will vary. Don't restrictyourself to a solution from the onset.

The job story format is:

- When `<situation>`
  - I want to `<motivation>`
    - So I can `<expected outcome>`
